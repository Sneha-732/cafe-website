# Velvet Bloom Café — Multi-page frontend website

This version is a **multi-page website**, not a single-page layout. Every top navigation item opens a separate HTML page with its own content, photos, and page-specific design.

## Pages
- `index.html` — home landing page, intro, featured menu categories, quote banner, visit teaser
- `menu.html` — dedicated menu page with separate Coffee & Tea, Brunch Plates, and Something Sweet sections, each with its own photo and item list
- `story.html` — brand story, founder note, values
- `space.html` — café interior gallery and experience details
- `journal.html` — journal feature and six article cards
- `visit.html` — address, hours, contact details, and directions link

## Run
1. Extract the ZIP.
2. Open `index.html` in a browser, or open the folder in VS Code and run Live Server.
3. Keep all HTML pages, `style.css`, and `script.js` together in the same folder.

## Customise
Replace the sample café name, address, email, hours, menu/prices, and social links before publishing. Photos and Google Fonts load online from Unsplash and Google Fonts. The address, email and menu prices are placeholders. The directions link is a generic map search; replace it with the café's real Google Maps URL.

This is a static frontend demo. It does not include backend ordering, table booking, or form submission.
